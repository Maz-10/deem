## 1. الهوية والموقع من السوق

| العنصر | القرار |
|---|---|
| الاسم | **ديم درون** — «ديم» هو المطر الهادئ المستمر الذي يغسل بلا عنف |
| النطاق المقترح | `deemdrone.sa` (و`deemdrone.com` تحويلًا) |

2. **أأمن**: صفر عمّال معلّقين، صفر إغلاق للأرصفة.
3. **مُثبَت**: مؤشر نظافة رقمي وصور قبل/بعد لكل زيارة.

## 2. خريطة الموقع

```
/                       الرئيسية
├── /services           الخدمات (6 خدمات + نطاق كل خدمة)
├── /technology         التقنية والسلامة (الأسطول، الماء النقي، التصاريح)
├── /pricing            الباقات والأسعار + حاسبة تقديرية
├── /about              من نحن (القصة، الفريق، الأثر البيئي)
├── /contact            طلب عرض سعر / مسح مجاني
└── /portal             بوابة العميل ← لوحة نظافة الواجهة (الرسوم البيانية)
```

**مسارات التحويل (Conversion paths)**
- المسار السريع: الرئيسية → زر «احجز مسحًا مجانيًا» → نموذج التواصل.
- المسار الباحث: الرئيسية → الخدمات → التقنية → الأسعار → التواصل.
- مسار العميل الحالي: أي صفحة → «بوابة العميل» → لوحة النظافة → طلب زيارة مبكرة.

## 3. بنية كل صفحة (Wireframe نصّي)

### 3.1 الرئيسية
1. **Hero**: عنوان + جملة داعمة + زرّان (احجز مسحًا مجانيًا / شاهد بوابة العميل) + شريط أرقام.
2. **شريط الثقة**: 4 أرقام (م² مغسولة، مبنى، ساعة طيران، حوادث = صفر).
3. **لماذا الدرون؟**: جدول مقارنة صريح مع الحبال والسقالات.
4. **الخدمات**: 6 بطاقات مختصرة → روابط للتفاصيل.
5. **كيف نعمل**: 5 خطوات (مسح → عرض سعر → تصاريح → تنفيذ → تقرير).
6. **القطاعات**: 6 شارات (أبراج مكتبية، فنادق، مولات، مستشفيات، طاقة شمسية، جهات حكومية).
7. **قسم الدليل الرقمي**: معاينة مصغّرة للرسم البياني + رابط البوابة. ← *نقطة التمايز، لا تُحذف*
8. **آراء العملاء** (3).
9. **الأسئلة الشائعة** (5 مطويّات).
10. **CTA ختامي** + التذييل.

### 3.2 بوابة العميل `/portal` — قلب المشروع
شاشة دخول تجريبية ← ثم لوحة مكوّنة من:

| # | المكوّن | الشكل البصري | ما يجيب عنه |
|---|---|---|---|
| 1 | **مؤشر النظافة الحالي** | رقم بطولي (Hero figure) + دلتا مقارنة بالشهر الماضي | «هل واجهتي نظيفة الآن؟» |
| 2 | بطاقات إحصائية (4) | آخر زيارة · الزيارة القادمة · م² مغسولة · لترات مياه موفَّرة | لمحة تشغيلية |
| 3 | **مؤشر النظافة عبر 12 شهرًا** | رسم خطي، سلسلتان: القياس الفعلي + الحد المتعاقد عليه، مع علامات الزيارات | «هل الخدمة تحافظ على المستوى؟» |
| 4 | **النظافة حسب الجهة** | أعمدة أفقية (شمالية/شرقية/جنوبية/غربية) | «أي جهة تتدهور؟» |
| 5 | **مصادر الاتساخ** | أعمدة مكدّسة لكل جهة (غبار · أملاح · بقع مطر · آثار طيور) | «لماذا تتسخ؟» |
| 6 | **استهلاك عقد الزيارات** | مقياس تعبئة (Meter) | «كم بقي من العقد؟» |
| 7 | **سجل الزيارات** | جدول (تاريخ، الجهات، المدة، الفني، المؤشر بعد الزيارة) | التوثيق والمحاسبة |
| 8 | **توصية آلية** | بطاقة تنبيه بحالة (جيد/تحذير/حرج) | ماذا أفعل الآن |

**قواعد إلزامية للرسوم** (مطبّقة في `assets/js/charts.js`):
- محور واحد فقط لكل رسم — لا محورين رأسيين إطلاقًا.
- ألوان السلاسل بترتيب ثابت لا يُدوَّر: أزرق → برتقالي → أخضر مائي → أصفر.
- لكل رسم **زر «عرض كجدول»** — إلزامي لأن الأخضر المائي والأصفر أقل من 3:1 تباينًا على السطح الفاتح.
- تلميح تفاعلي (tooltip) عند التحويم على كل رسم.
- ألوان الحالة (جيد/تحذير/حرج) لا تُستخدم كألوان سلاسل أبدًا، وتأتي دائمًا مع أيقونة ونص.
- الوضع الليلي بدرجات مختارة، لا انعكاس آلي.

## 4. القرارات التقنية

| القرار | الاختيار | السبب |
|---|---|---|
| البناء | HTML/CSS/JS خام، بلا خطوة بناء | موقع تسويقي 7 صفحات؛ الاعتماديات عبء بلا مقابل |
| الرسوم | مكتبة SVG داخلية (`charts.js`, ~14KB) | لا CDN، لا رخص، تحكم كامل بالوصولية والاتجاه |
| البيانات | `assets/data/*.json` الآن → REST API لاحقًا | نفس شكل البيانات، فيبقى الواجهة كما هي |
| الاتجاه | `dir="rtl"` على الصفحة، والرسوم داخليًا LTR (الزمن يسير يسارًا→يمينًا) | العرف المتّبع في لوحات BI العربية |
| الاستضافة | أي مضيف ثابت (Netlify / Cloudflare Pages / S3) | لا خادم مطلوب |
| الأداء | لا خطوط خارجية إلزامية، صور SVG، JS مؤجّل | هدف: LCP < 2.0s على 4G |

### مراحل ما بعد الإطلاق (خارج نطاق النسخة الأولى)
- **م1**: نموذج التواصل → API حقيقي (Formspree أو خادم مؤسسي) + إشعار واتساب للمبيعات.
- **م2**: مصادقة حقيقية للبوابة (OTP عبر الجوال) وربطها بقاعدة العملاء.
- **م3**: تغذية مؤشر النظافة آليًا من صور الدرون عبر نموذج رؤية حاسوبية بدل الإدخال اليدوي.
- **م4**: تطبيق ويب تقدمي (PWA) لمشرفي المواقع + توقيع رقمي لاستلام الزيارة.

## 5. تحسين محركات البحث (SEO)

**الكلمات المستهدفة**: تنظيف واجهات بالدرون · غسيل واجهات زجاجية الرياض · تنظيف الألواح الشمسية · تنظيف مباني بدون حبال · شركة تنظيف واجهات جدة.

- عنوان ووصف فريد لكل صفحة (مكتوبة جاهزة في `CONTENT.md`).
- Schema.org: `LocalBusiness` في الرئيسية، `Service` في صفحة الخدمات، `FAQPage` لقسم الأسئلة.
- `sitemap.xml` + `robots.txt` + `canonical` لكل صفحة.
- `og:image` مخصّصة لمشاركات واتساب ولينكدإن.
- صفحات مدينة لاحقًا (`/riyadh`, `/jeddah`) بعد استقرار المحتوى الأساسي.
