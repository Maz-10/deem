# ديم درون — موقع شركة تنظيف الواجهات بالطائرات المسيّرة

موقع تسويقي عربي (RTL) من سبع صفحات، أبرزها **بوابة العميل**: لوحة تعرض مؤشر نظافة واجهة
المبنى كرسوم بيانية عبر الزمن.

بلا خطوة بناء وبلا اعتماديات — HTML و CSS و JavaScript خام فقط.

## التشغيل

```bash
python3 -m http.server 8099
# ثم افتح http://localhost:8099
```

يعمل أيضًا بفتح `index.html` مباشرة من القرص (لهذا كانت بيانات العميل ملف `.js` لا `.json`).

## بوابة العميل

`portal.html` — أي بيانات دخول تفتح اللوحة (نسخة تجريبية)، أو `portal.html#dashboard` للدخول
المباشر. تعرض:

1. **مؤشر النظافة الكلي** رقمًا بطوليًا مع حالته والفرق عن المسح السابق.
2. **أربع بطاقات تشغيلية**: آخر زيارة، القادمة، المساحة المغسولة، المياه الموفَّرة.
3. **رسم خطي** للمؤشر عبر 12 شهرًا مقابل الحد المتعاقد عليه، مع علامات الزيارات.
4. **أعمدة أفقية** لمؤشر كل جهة من المبنى.
5. **أعمدة مكدّسة** لمصادر الاتساخ في كل جهة.
6. **مقياس** استهلاك عقد الزيارات + توصيات آلية + سجل الزيارات.

### قواعد الرسوم (مطبَّقة في الشيفرة لا في التعليقات)

- محور واحد لكل رسم — لا محورين رأسيين إطلاقًا.
- ألوان السلاسل بترتيب ثابت لا يُدوَّر، ومُتحقَّق من فصلها لعمى الألوان
  (ΔE ≥ 8 في وضعَي الإضاءة).
- لكل رسم **زر «عرض كجدول»** — إلزامي لأن لونين من السلاسل دون 3:1 تباينًا على السطح الفاتح.
- وسيلة إيضاح عند سلسلتين فأكثر، ولا وسيلة إيضاح لسلسلة واحدة.
- النص لا يرتدي لون البيانات؛ الشكل الملوّن بجانبه هو حامل الهوية.
- ألوان الحالة (جيد/تحذير/حرج) محجوزة، وتأتي دائمًا مع أيقونة ونص.
- الوضع الليلي بدرجات مختارة ومُتحقَّق منها، لا انعكاس آلي.
- الرسوم داخليًا `direction: ltr` رغم أن الصفحة RTL: الزمن يسير يسارًا←يمينًا،
  و RTL يعكس معنى `text-anchor` فيقلب كل التسميات.

## ربط البيانات الحقيقية

استبدل `assets/data/client-alnakheel.js` بنداء إلى:

```
GET /api/clients/:id/cleanliness
```

يعيد نفس شكل الكائن (`client`, `index`, `facades`, `soiling`, `stats`, `visits`)،
فلا يتغيّر أي سطر في `portal.js`.
