# ديم درون — موقع شركة تنظيف الواجهات بالطائرات المسيّرة

موقع تسويقي عربي (RTL) من سبع صفحات، أبرزها **بوابة العميل**: لوحة تعرض مؤشر نظافة واجهة
المبنى كرسوم بيانية عبر الزمن.

بلا خطوة بناء وبلا اعتماديات — HTML و CSS و JavaScript خام فقط.

## التشغيل

```bash
python3 -m http.server 8099
# ثم افتح http://localhost:8099
```

يعمل أيضًا بفتح `index.html` مباشرة من القرص (لهذا كانت بيانات العميل ملف `.js` لا `.json`).

## رابط المعاينة

```bash
python3 tools/build-artifact.py     # → build/deem-drone.html
```

يجمع السبع صفحات في ملف واحد بلا أي طلب خارجي: محتوى كل `<main>` يصبح قسمًا
يتنقّل بينها مُوجِّه بالـ hash (`#/services`)، والخطوط تُقلَّص إلى النطاقات
المستخدمة (387KB → 248KB) ثم تُضمَّن كـ data URI، و CSS و JS والبيانات داخل
الملف. الناتج ~504KB وصفر طلبات شبكة.

## وضع الآدمن — تحرير النصوص وحذفها

افتح أي صفحة بـ `?admin=1` (كلمة المرور `deem2026`) فيصبح **كل عنصر يحمل نصًا**
قابلًا للتحرير بالنقر، ويظهر زر حذف عند التحويم فوقه.

| العملية | كيف |
|---|---|
| تعديل نص | انقر النص، اكتب، ثم Enter أو انقر خارجه (Esc يلغي) |
| حذف عنصر | مرِّر فوقه ثم انقر ✕ |
| تصدير التعديلات | زر «تصدير JSON» — ملف لكل صفحة |
| استيراد | زر «استيراد» ثم اختر ملف JSON |
| تراجع كامل | زر «تراجع عن الكل» |
| إنهاء | زر «إنهاء التحرير» |

المفتاح لكل عنصر مشتقّ من موقعه في شجرة الصفحة، والتعديلات تُحفظ في
`localStorage` تحت `deem-cms:<اسم الصفحة>` وتُطبَّق عند كل فتح.

**حدود هذه النسخة** — مكتوبة في واجهتها ولا تُخفى:
- التخزين محلي في المتصفح، فالتعديلات لا تظهر لزوّار آخرين حتى تُصدَّر.
- كلمة المرور في الواجهة فقط، وليست حماية أمنية.
- إعادة ترتيب عناصر الصفحة في الـ HTML تكسر المفاتيح؛ ملف التصدير هو طريق الترحيل.

للإنتاج: مصادقة على الخادم و `PUT /api/content` بنفس شكل ملف التصدير.

## الهوية البصرية

**الألوان مستخرجة من فقاعات الشعار بالبكسل، لا مقدَّرة بالعين.**

| الرمز | فاتح | داكن | الاستعمال |
|---|---|---|---|
| `--brand-ink` | `#161c26` | `#12171f` | أرضية الشعار — الرأس والهيرو والتذييل |
| `--brand` | `#467480` | `#5e9aaa` | الأزرار وحلقة التركيز |
| `--brand-strong` | `#3a5f69` | `#7cc3c3` | الروابط والنصوص المميّزة |
| `--brand-wash` | `#ecf3f5` | `#1b2830` | خلفيات هادئة |
| `--bubble-blue/aqua/sage/mint` | `#5e9aaa` `#7cc3c3` `#79a98a` `#93cfa8` | كما هي | لمسات وزخارف فقط |

ألوان الفقاعات نفسها فاتحة (3.1:1 مع الأبيض) فلا تصلح أسطحًا لنص أبيض، لذلك اشتُقّت
منها درجات أغمق للعناصر التفاعلية وبقيت الأصلية للّمسات. كل زوج (نص/خلفية) في النظام
يجتاز 4.5:1، وحلقات التركيز تجتاز 3:1.

**ألوان الرسوم البيانية لم تُستبدل عمدًا.** لوحة السلاسل مُتحقَّق من فصلها لعمى الألوان
(ΔE ≥ 8)، وألوان الفقاعات الأربعة متجاورة في درجة اللون ومنخفضة التشبّع فتفشل هذا الفحص
لو استُخدمت كسلاسل. الرسوم طبقة وظيفية على سطح بطاقتها الخاصة. الاستثناء: الخط المصغّر
في الرئيسية سلسلة واحدة بلا قيد فصل، فأخذ لون الهوية.

## الطباعة

خطوط **ثمانية**، محوّلة من OTF إلى WOFF2 (78KB بدل 242KB):

| الاستعمال | الخط |
|---|---|
| العناوين h1/h2 | Thmanyah Serif Display Medium |
| الفقرات التمهيدية والاقتباسات | Thmanyah Serif Text Regular |
| المتن والواجهة | Thmanyah Sans Regular |
| العناوين الفرعية والأزرار والتسميات | Thmanyah Sans Medium |
| الأرقام الكبيرة والشعار | Thmanyah Sans Black |

الأوزان معلنة كنطاقات في `@font-face` حتى لا يصطنع المتصفح وزنًا غير موجود.

## بوابة العميل

`portal.html` — أي بيانات دخول تفتح اللوحة (نسخة تجريبية)، أو `portal.html#dashboard` للدخول
المباشر. تعرض:

1. **مؤشر النظافة الكلي** رقمًا بطوليًا مع حالته والفرق عن المسح السابق.
2. **أربع بطاقات تشغيلية**: آخر زيارة، القادمة، المساحة المغسولة، المياه الموفَّرة.
3. **رسم خطي** للمؤشر عبر 12 شهرًا مقابل الحد المتعاقد عليه، مع علامات الزيارات.
4. **أعمدة أفقية** لمؤشر كل جهة من المبنى.
5. **أعمدة مكدّسة** لمصادر الاتساخ في كل جهة.
6. **مقياس** استهلاك عقد الزيارات + توصيات آلية + سجل الزيارات.

### قواعد الرسوم (مطبَّقة في الشيفرة لا في التعليقات)

- محور واحد لكل رسم — لا محورين رأسيين إطلاقًا.
- ألوان السلاسل بترتيب ثابت لا يُدوَّر، ومُتحقَّق من فصلها لعمى الألوان
  (ΔE ≥ 8 في وضعَي الإضاءة).
- لكل رسم **زر «عرض كجدول»** — إلزامي لأن لونين من السلاسل دون 3:1 تباينًا على السطح الفاتح.
- وسيلة إيضاح عند سلسلتين فأكثر، ولا وسيلة إيضاح لسلسلة واحدة.
- النص لا يرتدي لون البيانات؛ الشكل الملوّن بجانبه هو حامل الهوية.
- ألوان الحالة (جيد/تحذير/حرج) محجوزة، وتأتي دائمًا مع أيقونة ونص.
- الوضع الليلي بدرجات مختارة ومُتحقَّق منها، لا انعكاس آلي.
- الرسوم داخليًا `direction: ltr` رغم أن الصفحة RTL: الزمن يسير يسارًا←يمينًا،
  و RTL يعكس معنى `text-anchor` فيقلب كل التسميات.

## ربط البيانات الحقيقية

استبدل `assets/data/client-alnakheel.js` بنداء إلى:

```
GET /api/clients/:id/cleanliness
```

يعيد نفس شكل الكائن (`client`, `index`, `facades`, `soiling`, `stats`, `visits`)،
فلا يتغيّر أي سطر في `portal.js`.
