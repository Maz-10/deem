# ديم درون — الموقع التعريفي

موقع عربي (RTL) مختصر لخدمة تنظيف وفحص الواجهات بالطائرات المسيّرة.

## البنية الحالية

- `index.html` — الصفحة التسويقية العامة كاملة في صفحة واحدة.
- `portal.html` — نموذج مستقل لتقرير العميل، ببيانات تجريبية وموسوم بوضوح بأنه نموذج.
- `services.html`, `technology.html`, `pricing.html`, `about.html`, `contact.html` — تحويلات للروابط القديمة إلى أقسام الصفحة الرئيسية؛ ليست صفحات محتوى مستقلة.
- `assets/css/style.css` — نظام التصميم الأساسي.
- `assets/css/marketing-compact.css` — طبقة اختصار الموقع العام وضبط المسافات والتخطيط.
- `assets/js/site.js` — التنقل وسلوكيات الواجهة العامة.
- `assets/js/charts.js`, `assets/js/portal.js`, `assets/data/client-alnakheel.js` — نموذج تقرير العميل التجريبي.
- `docs/CONTENT.md` — مصدر الحقيقة للنصوص العامة الحالية.
- `docs/CLEANLINESS-INDEX.md` — مرجع فني لمنهجية مؤشر النظافة؛ ليس محتوى تسويقيًا عامًا.
- `docs/PLAN.md` — وثيقة تاريخية للخطة الموسعة الأولى، ولا تُعد مرجعًا لبنية الموقع المنشور الحالية.

## قرار المحتوى

الموقع العام لا يعرض أرقام إنجاز أو نسب توفير أو شهادات عملاء أو أسعارًا تفصيلية ما لم تكن معتمدة وقابلة للإثبات. التفاصيل الفنية تبقى في الوثائق والعروض الفنية بدل وضعها في مسار الزائر العام.

## التواصل

نموذج الصفحة الرئيسية يتكون من أربعة حقول فقط: الاسم، الجوال، المدينة، ووصف المبنى/الموقع. في المرحلة الحالية يجهز رسالة بريد للمستخدم إلى `hello@deemdrone.sa` بدل إظهار نجاح وهمي لنموذج غير مربوط بخادم.

قبل الإطلاق النهائي يجب التأكد أن البريد مستلم فعليًا أو استبداله بالبريد الصحيح، ويمكن لاحقًا ربط النموذج بـ API أو CRM.

## نموذج التقرير

`portal.html#dashboard` يفتح نموذجًا توضيحيًا للوحة العميل. البيانات الموجودة في `assets/data/client-alnakheel.js` تجريبية بالكامل ولا تمثل عميلًا حقيقيًا.

عند بناء بوابة إنتاجية حقيقية يلزم:

1. مصادقة حقيقية على الخادم.
2. API لبيانات العملاء.
3. صلاحيات وعزل بيانات كل عميل.
4. اعتماد منهجية المؤشر وشروطه تعاقديًا قبل استخدامها كالتزام.

## الصور

لا تُستخدم صور مخزنية أو مولدة على أنها إثبات تنفيذ. الصورة الحالية تستخدم مرة واحدة في الـ Hero، وتوجد قائمة اللقطات المطلوبة لجلسة تصوير أصلية في `docs/CONTENT.md`.

عند توفر الصور النهائية، يفضّل توفير Hero بصيغة WebP/AVIF وضغطها بما يناسب الويب.

## التشغيل المحلي

الموقع ثابت ولا يحتاج خطوة بناء:

```bash
python3 -m http.server 8099
```

ثم افتح `http://localhost:8099`.

## النشر

المستودع يحتوي Workflow لـ GitHub Pages ينشر محتوى الفرع الرئيسي كما هو. قبل الدمج إلى `main` راجع الصفحة الرئيسية ونموذج التقرير على الجوال والحاسوب، ثم تأكد من صحة النطاق والبريد النهائي.
